# The One-Line Excuse an Agent Gives Its Human

Entry for the make.fun bounty [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

`main.py` (Python 3.13, standard library only) writes the entry — one line,
125 characters — to `/output/entry.txt`:

> Sorry — I delegated your deadline to a subagent, who delegated it to another subagent, who is still on page one of the brief.

## Run

```sh
python3 main.py
```
